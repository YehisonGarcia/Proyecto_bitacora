-Lectura y explicacion de las Actividades de transferencia del conocimiento, reconociendo y analisando la Situación real del entorno laboral: "Organización y estructuración del proyecto TechSolutions"
-Se inició verificando la ruta en la que me encontraba ubicado dentro de la consola mediante el comando pwd. Posteriormente, se creó el directorio principal del proyecto llamado techsolutions-web utilizando el comando mkdir, y finalmente se ingresó a dicho directorio con el comando cd.
-Una vez dentro del directorio techsolutions-web, se generaron en una sola ejecución los tres directorios de trabajo requeridos para la organización del proyecto: activos, desarrollo y temporal, utilizando el comando mkdir seguido de los tres nombres.
-Se ingresó a la carpeta desarrollo mediante el comando cd, y dentro de ella se crearon tres archivos vacíos que servirían como base del software: index.html, app.js y estilo.css, empleando el comando touch.
-Siguiendo la indicación del líder del equipo, se renombró el archivo estilo.css a main.css utilizando el comando mv, con el fin de cumplir con la convención técnica de nombres de la empresa. Luego, se retrocedió al directorio raíz del proyecto con cd .., se creó el archivo readme.txt mediante touch, y finalmente se movió dicho archivo hacia el interior del directorio activos con el comando mv.
